Explorá los principales conceptos

La Distribución Gamma es una distribución continua utilizada principalmente para modelar variables positivas, tiempos de espera, duración y tiempo hasta que ocurren varios eventos.

Síntesis de la Distribución Gamma

Tipo
Distribución continua
Dominio
X > 0
Parámetro de forma
α
Parámetro de escala
β
Esperanza
E(X) = αβ
Varianza
V(X) = αβ²
Aplicación principal
Tiempos de espera, duración y variables continuas positivas
Caso particular
Exponencial cuando α = 1
